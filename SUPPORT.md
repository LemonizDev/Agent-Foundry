# Support

- **Usage and setup:** read the [User Guide](docs/USER_GUIDE.md) and [Bootstrap Guide](BOOTSTRAP.md).
- **Bug reports:** open a GitHub issue with the CLI version, operating system, Node.js version, exact command, expected result and actual result. Remove secrets and private paths first.
- **Feature requests:** describe the user problem, expected workflow, host/tool and version, and why existing resources do not solve it.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Do not post exploitable details or credentials in public issues.

Agent Foundry is under active development. Check the README's project status before relying on a capability in production.
