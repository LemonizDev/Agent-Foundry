# Support

- **Usage and setup:** read the User Guide and Bootstrap Guide.
- **Bug reports:** include the repository commit, coding-agent host and version, expected behaviour, actual behaviour and a minimal reproduction. Remove secrets and private paths.
- **Feature requests:** describe the user problem, intended conversational workflow and why existing context resources do not solve it.
- **Security issues:** follow SECURITY.md. Do not post exploitable details or credentials in public.

Agent Foundry is under active development. Check the README for current project status and host acceptance limitations.
