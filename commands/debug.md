# Debug

## Invocation

/debug [symptom or failing behaviour]

## Behaviour

Run Evidence-Led Debugging. Reproduce the issue, form competing hypotheses, test them with discriminating experiments, isolate the root cause, add regression protection and verify adjacent behaviour. Do not make speculative code changes before establishing evidence.
