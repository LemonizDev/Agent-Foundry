# Delegate

## Invocation

/delegate [task or workstream]

## Behaviour

Classify the task type, intensity, risk, context and tool requirements. Consult the project model roster and explain the selected worker and rationale. Create a bounded assignment with objective, non-goals, file ownership, context, expected output, acceptance criteria, tests, checkpoint and recovery policy. If the host cannot dispatch subagents, produce the assignment for manual execution. Lead accountability remains with the current agent.
